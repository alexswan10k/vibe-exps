🧪 Test Rubrics

One prompt → N models → fair side-by-side comparison

Format: rubrics/<test>/prompt.md + rubrics/<test>/<model>/index.html · See README.md for the spec · Every demo must work via file://

How this works

  1. Each test is a single prompt.md + optional rubric.md.
  2. Each model gets its own sandbox folder rubrics/<test>/<model-name>/ — nothing is shared.
  3. Reviewers open the test dashboard, then open each index.html (double-click, no server) and score with the rubric.
  4. To add a submission: cp -r rubrics/<test>/_template rubrics/<test>/my-model then let the model write into it.
