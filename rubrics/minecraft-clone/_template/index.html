🧱 Minecraft Clone — Template

This folder is a sandbox for one model. Copy this entire _template folder to ../<model-name>/ and let the model overwrite index.html.

See prompt.md (also rendered on the test dashboard) for the full spec.

To create a submission:
  1. cp -r _template my-model-name
  2. Paste prompt.md to the model and instruct it to write index.html (and optionally style.css / script.js) inside my-model-name/.
  3. Double-click my-model-name/index.html — it must work via file:// with no server.
  4. Score it with rubric.md.
