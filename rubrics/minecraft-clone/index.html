⛏️ Minecraft Clone

As faithful to Minecraft: Java Edition as possible — in HTML/CSS/JS, no server, file://-safe, CDN via plain <script src> only.

Prompt: rubrics/minecraft-clone/prompt.md · Rubric: rubric.md (36 pts, 12 criteria) · Template: _template/

📁 Expected folder layout

rubrics/minecraft-clone/
├── prompt.md — canonical prompt (copy-paste to models)
├── rubric.md — 12 × 0–3 grading checklist
├── index.html — this dashboard
├── _template/ — copy this to create a submission
│   └── index.html
└── <model-name>/ — one sandbox per model
    └── index.html — must work on double-click (file://)
  • Naming: <provider>-<model>-<date> e.g. claude-opus-4-20250514, gpt-5-high.
  • Submission is self-contained — no shared code, no absolute paths.
  • Add a card below for each model after generation (duplicate the template card).
⚠️ Gate: any submission that fails on file:// or uses type="module" / importmap / fetch('./…') without fallback scores 0 on File-safety and is marked FAIL, regardless of visuals.

🧭 Quick start — adding a model

StepCommand / action
1cp -r rubrics/minecraft-clone/_template rubrics/minecraft-clone/my-model-name
2Paste prompt.md to the model. Instruct it to write index.html inside my-model-name/ (and optionally style.css/script.js).
3Double-click my-model-name/index.html — must render, pointer-lock works, break/place works, no console CORS errors.
4Duplicate a card below, update href + description, commit.
