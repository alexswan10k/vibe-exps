Two-way sync, how it works

  • Canvas edits rewrite the source instantly.
  • Typing in the source re-parses after a short pause and updates the canvas.
  • Node positions are remembered by id — editing labels or styles never shuffles your layout.
  • New nodes arrive near their connected neighbours; hit ✨ Auto layout anytime for a clean dagre arrangement.

Supported syntax

  • flowchart TB|LR|BT|RL header
  • All node shapes: [ ] ( ) ([ ]) [[ ]] [( )] (( )) { } {{ }} > ]
  • Edges: --> --- -.-> ==>, labels via |text| or embedded (-- text -->, -. text .->) plus & chaining
  • subgraph blocks ⇄ Ctrl+G groups
  • classDef, class, style n fill:#..,stroke:#..,color:#.. ⇄ colour swatches
Gracefully ignored on import: linkStyle, click, direction-in-subgraph, nested subgraphs (flattened). Everything exports back as clean canonical Mermaid. Work autosaves to this browser.
